Selected Work

01

힙합 소셜 비디오 플랫폼

  • React Native
  • Redux
  • Mobile App
02

블록체인 기반 데이팅 앱

  • 마켓 리서치
  • Java
  • Kotlin
  • Vue.js
03

미술품 공동 투자 플랫폼

  • 프로덕트 설계
  • UI/UX
  • Mobile App
